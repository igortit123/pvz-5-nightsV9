ТЕКСТУРЫ ДЛЯ ИГРЫ "5 ночей в ПВЗ"
Положите папку textures рядом с index.html. Любой файл можно заменить своим (PNG, имя точно такое же).
Какого файла нет, вместо него игра нарисует свою текстуру.

Посылки:  box1..box3 картон, box4 синяя, box5 белая, box6 фиолетовая
Вывески и плакаты:  sign_front.png  sign_back.png  poster_card.png  poster_map.png
Двери и пол:  door_storage.png (склад)  door_glass.png (входная)  mat.png (коврик)
Клиенты (светлые, игра красит одежду и кожу в разные цвета):
  client_body.png (одежда)  client_pants.png (штаны)  client_skin.png (кожа)
  client_face.png (лицо, прозрачный фон)
Монстры:
  monster_face.png (лицо монстра-клиента, прозрачный фон, видно при свете фонаря)
  monster_skin.png  monster_body.png
