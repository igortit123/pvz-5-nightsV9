ЗВУКИ ДЛЯ ИГРЫ "5 ночей в ПВЗ"
Положите папку sounds рядом с index.html. Любой файл можно заменить своим (mp3, ogg или wav, имя точно такое же).
Какого файла нет, вместо него игра синтезирует звук сама.

beep   - писк сканера при нажатии
ok     - заказ успешно выдан
err    - ошибка, жалоба, клиент ушёл
chime  - звонок над дверью, входит клиент
click  - включение и выключение фонарика
step   - один шаг клиента (короткий)
creak  - скрип двери склада
slam   - хлопок двери склада
growl  - рык монстра из склада
hiss   - шипение, монстр убегает
scare  - скример (громкий)
